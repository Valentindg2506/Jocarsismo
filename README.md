# 🕍 Jocarsismo · Iglesia del Santo Jocarsa

Página web paródica y afectuosa dedicada a la cultura Linux, el software libre y las costumbres de los desarrolladores. Nació como broma para el profesor y acabó siendo un pequeño recurso didáctico: enseña buenas prácticas (hacer commits, documentar, tener copias de seguridad) a través del humor.

## Qué es

Un “templo” web con todo lo que tendría una iglesia, pero trasladado al mundo del desarrollo: dogmas, liturgia, una comunidad de fieles, preguntas frecuentes y hasta una biblia propia. Detrás del tono de broma hay mensajes reales sobre cómo trabajar mejor con código.

## Qué tiene

- **El templo** (`index.html`): portada, dogmas, liturgia, comunidad, preguntas frecuentes y confesionario.
- **La biblia virtual** (`biblia.html`): textos divididos en siete libros (Kernel, Distros, Jocarsa, Mandamientos, Cartas, Gedit y Apocalipsis), con navegación por libros y capítulos.
- **Confesionario tecnológico**: eliges tu pecado de programador y recibes una penitencia al azar.
- **Easter eggs**: una pantalla azul de Windows simulada, un oráculo del kernel y sorpresas al interactuar con cartas y dogmas.
- **Pequeñas interacciones**: contador de bendiciones, botones de “Amén” en cada sección y versículo del día.
- **Accesibilidad básica**: HTML semántico, navegación por anclas y roles ARIA en las ventanas modales.

## Cómo está hecho

HTML, CSS y JavaScript puros, sin frameworks. Toda la interactividad (confesionario, pantalla azul, oráculo, contadores) vive en `assets/js/app.js`, y los estilos en `assets/css/style.css`.
