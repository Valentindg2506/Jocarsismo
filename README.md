**Descripción**

- 🕍 **Proyecto:** Iglesia del Santo Jocarsa — página paródica y afectuosa dedicada a la cultura Linux, el software libre y las costumbres de los desarrolladores. Creada como broma para el profesor y como recurso didáctico informal.
- 🎯 **Propósito:** entretener y concienciar sobre buenas prácticas (commits, documentación, backups) mediante humor y pequeñas interacciones frontend.

**Contenido principal**

- 📄 Página principal: [index.html](Jocarsismo/index.html) — templo web con hero, dogmas, liturgia, confesionario y easter eggs.
- 📖 Biblia virtual: [biblia.html](Jocarsismo/biblia.html) — colección de textos en siete libros (Kernel, Distros, Jocarsa, Mandamientos, Cartas, Gedit, Apocalipsis).
- ⚙️ Recursos: `assets/` — contiene `css/`, `js/` y la imagen principal `jocarsa.png`.

**Características destacadas**

- 🙏 Confesionario Tecnológico: formulario / selector con penitencias humorísticas y respuestas aleatorias.
- 💥 Easter eggs: BSOD simulado, oráculo del Kernel, y pequeñas sorpresas al interactuar con las cartas y dogmas.
- 🔢 Interacciones simples: contador de bendiciones, botones de "Amén" por sección y búsqueda de verso del día.
- ♿ Accesibilidad básica: estructura semántica, navegación por anclas y manejo de roles ARIA en elementos modales.

**Estructura del proyecto**

- `index.html` — Página principal del templo.
- `biblia.html` — Textos extendidos y navegación por libros.
- `assets/css/style.css` — Estilos principales.
- `assets/js/app.js` — Lógica de interacciones (confesionario, BSOD, oráculo, contadores, etc.).

**Cómo leer este repositorio**

- Usa el navegador para abrir `index.html` y navegar por las secciones: Dogmas, Liturgia, Comunidad y FAQ.
- Abre `biblia.html` para acceder a los textos largos divididos en libros y capítulos.
- Revisa `assets/js/app.js` para ver cómo están implementadas las interacciones front-end.
